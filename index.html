ARBILEX

Observatoire Empirique du Contentieux Post-Arbitral

Un observatoire en ligne de données empiriques sur le contentieux post-arbitral. Collecte, codage et analyse systématique des décisions judiciaires relatives aux recours contre les sentences arbitrales aux États-Unis et en France.

Données en cours de collecte — Août 2026

Le projet

Question de recherche

L'arrivée de l'IA générative a-t-elle modifié les pratiques argumentatives dans le contentieux post-arbitral fédéral américain ? Analyse quantitative sur trois périodes (2018–2026).

Approche empirique

Collecte exhaustive via les API de CourtListener (États-Unis) et Judilibre (France). Codage systématique des variables structurelles de chaque décision. Analyse statistique (ANOVA, chi-deux).

Dimension comparatiste

Volet américain : motions to vacate (Section 10 FAA). Volet français : reconnaissance et exequatur des sentences arbitrales étrangères. Perspective d'extension au Brésil (STJ).

Sources de données

CourtListener

Base de données open-source du Free Law Project. Texte intégral des décisions fédérales américaines. API v4 gratuite. Couverture : tous les circuits fédéraux.

API REST Open Source Texte intégral

Judilibre

Base ouverte de la Cour de cassation française, accessible via le portail PISTE du gouvernement. Décisions de la Cour de cassation et des cours d'appel.
